## 6. Технические замечания

- Страницы сайта при обращении без браузера отвечают HTTP 401 «Проверка безопасности»; во встроенном браузере проверка прошла незаметно (в сетевом журнале: `POST /api/v1/behavior/verify` → 403, затем `captcha/gen` и `captcha/verify` → 200). Образы с `cdn.pamyat-naroda.ru` скачиваются напрямую (с заголовком Referer).
- Адрес образа на карточке героя берётся из тега `<img>` просмотрщика (`https://cdn.pamyat-naroda.ru/images3/…`); на странице документа — из атрибута `data-source` пунктов переключателя страниц (`select.document-page-selector`), откуда и взяты номера кадров: `https://cdn.pamyat-naroda.ru/images/<передача>/<фонд-опись-дело>/<кадр>.jpg`.
- Названия, даты, номера и архивные шифры документов приведены так, как показаны на сайте; содержание образов (кроме отмеченных предварительных чтений дат и отдельных фраз) не расшифровывалось — это задача следующего этапа (внесение в реестры дела A-/C-).
- Общий объём образов ≈ 65 МБ, из них 13,7 МБ — полный лист карты.
