# Задание 2 для локальной сессии Claude Code (встроенный браузер): документы с «Памяти народа»

Скопируйте текст ниже в локальную сессию Claude Code на своём компьютере (в папке-клоне `oloendithas/draft`). Если сайт покажет проверку безопасности или CAPTCHA, пройдите её сами в открытой вкладке. Обходить защиту не нужно.

---

**Контекст.** В репозитории `oloendithas/draft`, ветка `claude/eager-rubin-khv5bi`, идёт генеалогическое исследование (папка `kinship-cases/shogenov-zalimgeri/`). Сержант Шогенов (Шагенов) Залимгери (Залим) Каральбиевич, 1916 г. р., из с. Старый Черек (КБАССР), был командиром стрелкового отделения 1288-го стрелкового полка 113-й стрелковой дивизии (64 ск, 57 А). Он убит 19.08.1943 у с. Боровое Харьковской обл. В декабре 1941 г. Урванский РВК отправил его в команде № 053 «в распоряжение 3-го Нацкавполка 115-й Нацкавдивизии». Первое задание уже выполнено: его файлы и инвентарь лежат в `kinship-cases/shogenov-zalimgeri/user-materials/pamyat-naroda/` (см. `README.md` там же). Уже скачанные файлы повторно не качать.

**Куда сохранять.** Новая папка `kinship-cases/shogenov-zalimgeri/user-materials/pamyat-naroda-2/`. Имена файлов — как в первом задании: `<часть>_<тип>_No<номер>_<дата>_tsamo-<фонд>-<опись>-<дело>_p<стр.>_f<кадр>.jpg` (для наградных — `nagrada_<фамилия>-<имя>_<номер записи>_f<кадр>.jpg`). Образы брать по прямым ссылкам `cdn.pamyat-naroda.ru` из просмотрщика, как в первом задании.

## Что сделать

1. Переключиться на ветку и обновить её:
   `git fetch origin && git checkout claude/eager-rubin-khv5bi && git pull`

2. **Наградные документы офицеров 1288 сп за август–сентябрь 1943 г.** Цель — найти описания боёв 17–21.08.1943 у Борового и высоты 198,9.
   - Поиск по людям https://pamyat-naroda.ru/heroes/ с фильтром по награждениям, часть «1288 сп» (варианты: «1288 стрелковый полк», «1288 сп 113 сд»). Указать период подвига или даты приказа: август – октябрь 1943 г.
   - Обязательно поискать по фамилиям из журнала боевых действий 113 сд: **Ермолинский** (ст. лейтенант, командир 2-го батальона 1288 сп; варианты Ермошинский, Ермолинской) и **Журавлев** (лейтенант, командир роты 2-го батальона). Также найти командира 1288 сп в августе 1943 г.: его фамилию дают наградные и приказы.
   - Скачивать наградной лист и строку приказа о награждении, если в описании подвига есть хотя бы одно из слов: Боровое (Боровая), Водяное, Зидьки (Звидки), Константовка (Константиновка), высота 198,9, 189,7 или 175,2, 17–21 августа. Скачивать также всё, где упомянут **Шагенов/Шогенов**.
   - Сделать сплошной поиск по наградным приказам 113 сд и 1288 сп за август–октябрь 1943 г. (раздел «Документы», тип «приказы», часть 113 сд). Если в описаниях есть погибшие сержанты, тоже проверить на «Шагенов/Шогенов/Залим».
   - В README для каждого найденного: ФИО, звание, должность, награда, номер приказа и дата, архивный шифр (ЦАМО, ф. 33, оп. …, д. …), ссылка, дословная цитата места о боях 17–21.08.

3. **Документы 115-й Кабардино-Балкарской кавалерийской дивизии (декабрь 1941 – октябрь 1942).** Цель — подтвердить, что он служил в этой дивизии, и найти, куда его перевели.
   - Найти страницу части «115 кавалерийская дивизия» (или «115 кд», «115 Кабардино-Балкарская кд») на https://pamyat-naroda.ru/warunit/ и её полки (278, 297, 316 кавполки — уточнить, какой из них назывался «3-м»). Записать в README данные страницы части: даты формирования и расформирования, командиры, подчинённость, список полков.
   - В разделе «Документы» дивизии и полков скачать: приказы о формировании и о расформировании (передаче личного состава); ЖБД дивизии (страницы о формировании в декабре 1941 – январе 1942 г. и о расформировании в сентябре–октябре 1942 г.); донесения о потерях за 1942 г., если есть.
   - В поиске по людям искать **Шагенов / Шогенов / Шопенов** с именами **Залимгери / Залим / Галим**, фильтр по части 115 кд или её полкам. Скачать все найденные карточки и образы, в том числе записи о ранениях и госпиталях за 1942–1943 гг.
   - Поискать донесения о безвозвратных потерях 115 кд за 1942 г. по жителям Старого Черека. Если отыщется донесение с длинным списком уроженцев Урванского района, достаточно скачать страницы со Ст. Череком.

4. **Документы 113 сд за 22 августа 1943 г.** (ID — из раздела 4.1 README первого задания; ссылка `https://pamyat-naroda.ru/documents/view/?id=<ID>`):
   - 112453375 и 112028104 — оперсводка № 317 (обе копии);
   - 112110324 — боевое донесение № 159;
   - 112028102 и 112110325 — боевое донесение № 160 (обе копии);
   - 136522522 — боевое распоряжение № 30;
   - 451287543 — оперсводка КАД-113 № 162;
   - 153719639 — «Выполнить ранее спущенный приказ»;
   - 454434879 — сведения о боеприпасах артиллерии № 484 (только если ≤ 2 страниц).
   Дополнительно, если найдётся: следующие страницы ЖБД 113 сд (https://pamyat-naroda.ru/documents/view/?id=131986933, страницы 53–60 просмотрщика, 25–31.08.1943) и донесение о потерях 113 сд за август 1943 г.

5. **Дополнительно, если хватит времени:** в деле списков призыва ВК КБР № 11008085 (карточка https://pamyat-naroda.ru/heroes/rvk-chelovek_voenkomat40486442/) скачать соседние кадры 105 и 110 и, если просмотрщик позволяет, другие списки команд Урванского РВК за декабрь 1941 г. По ним можно определить год в карандашной помете «30/XII 194[4]» под списком команды 053.

6. Написать `kinship-cases/shogenov-zalimgeri/user-materials/pamyat-naroda-2/README.md`. Указать дату сбора, точные поисковые запросы со ссылками и числом результатов, а также что не найдено. По каждому файлу — URL, тип документа, дата, автор/подписи, архивный шифр (фонд/опись/дело), страница просмотрщика и кадр. Посчитать контрольные суммы: `sha256sum *.jpg *.png > SHA256SUMS.txt` в той же папке.

7. Закоммитить и запушить:
   `git add kinship-cases/shogenov-zalimgeri/user-materials && git commit -m "Материалы с Памяти народа, задание 2: наградные 1288 сп, 115 кд, 113 сд за 22.08.1943" && git push origin claude/eager-rubin-khv5bi`

**Готово**, когда файлы, README и SHA256SUMS лежат в ветке на GitHub. Если документ не открывается, раздел требует входа или поиск ничего не дал, записать это в README с точным запросом. Пустой результат тоже нужен для дела. Сведения о живых людях не собирать.
