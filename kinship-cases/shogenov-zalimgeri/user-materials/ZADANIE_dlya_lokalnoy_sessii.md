# Задание для локальной сессии Claude Code (встроенный браузер): документы с «Памяти народа»

Скопируйте текст ниже в локальную сессию Claude Code на своём компьютере (в папке-клоне `oloendithas/draft`). CAPTCHA на сайте проходите сами в открытой вкладке.

---

Контекст. В репозитории `oloendithas/draft`, ветка `claude/eager-rubin-khv5bi`, идёт генеалогическое исследование (папка `kinship-cases/shogenov-zalimgeri/`): сержант Шогенов (в документах части — Шагенов) Залимгери (Залим) Каральбиевич, 1916 г. р., уроженец с. Старый Черек Урванского р-на Кабардино-Балкарской АССР, командир стрелкового отделения 1288-го стрелкового полка 113-й стрелковой дивизии, убит 19.08.1943 у д. Боровое (Боровая) Змиевского р-на Харьковской обл. Облачная сессия не может открыть сайт pamyat-naroda.ru (CAPTCHA «защита от автоматических запросов»), поэтому документы оттуда нужно собрать во встроенном браузере. CAPTCHA и вход проходит сам пользователь — не пытайся её решать автоматически; если она появилась, попроси пользователя пройти её в открытой вкладке и продолжай.

Что сделать.
1. Переключиться на ветку `claude/eager-rubin-khv5bi` (`git fetch origin && git checkout claude/eager-rubin-khv5bi && git pull`). Папка для материалов: `kinship-cases/shogenov-zalimgeri/user-materials/pamyat-naroda/`.
2. Во встроенном браузере открыть поиск https://pamyat-naroda.ru/heroes/?adv_search=y&last_name=Шогенов&first_name=Залимгери&group=all и затем поиск по «Шагенов Залим» (группа «все документы»). Ожидаются записи: «Шагенов Залим Карабаевич», «Шагенов Галим Карабаевич», «Шогенов Залимгери Каральбиевич», «Шагенов Залимгери Каральб.», «ШОПЕНОВ Залимгери Каральбиевич». Для КАЖДОЙ записи: открыть карточку, сохранить её URL, тип документа и все поля (текстом в README), скачать образ документа кнопкой скачивания (или сделать полноэкранный скриншот образа) в файл с говорящим именем, например `hero_shagenov-zalimgeri-karalb_<тип>.jpg`. Особенно важна запись «Шагенов Залимгери Каральб.» — её в ОБД «Мемориал» нет; выписать, из какой это картотеки (ВПП, награждений, учётно-послужной и т. п.) и все даты/места (призыв, прибытие, выбытие, награда).
3. На карточке героя открыть вкладку «Боевой путь» и перейти на страницу части (113 сд или 1288 сп). В разделе «Документы» части найти и скачать: журнал боевых действий 113 сд за август 1943 г. (страницы за 15–22 августа), боевые донесения и оперативные сводки 113 сд и 1288 сп за 17–21 августа 1943 г., карты положения частей у с. Боровая / ст. Зидьки / р. Уды (если есть). Для каждого документа записать URL (`pamyat-naroda.ru/documents/view/?id=...`), название, даты, номера скачанных страниц.
4. Открыть и скачать страницы за 17–21 августа из двух выписок из ЖБД 57-й армии: https://pamyat-naroda.ru/documents/view/?id=133726633 и https://pamyat-naroda.ru/documents/view/?id=113985195 .
5. Если на карточке героя есть вкладка «Награды» — сохранить её содержимое и образы.
6. Написать `kinship-cases/shogenov-zalimgeri/user-materials/pamyat-naroda/README.md`: дата сбора, список файлов, для каждого — URL, тип документа, архивный шифр (фонд/опись/дело, если показан), что на нём. Не включать никаких сведений о живых людях.
7. Закоммитить и запушить в ветку `claude/eager-rubin-khv5bi`: `git add kinship-cases/shogenov-zalimgeri/user-materials && git commit -m "Материалы с Памяти народа о Шогенове Залимгери" && git push`.

Готово, когда файлы и README лежат в ветке на GitHub. Если какой-то документ не открывается или сайт снова требует проверку — записать это в README и продолжить с остальным.
