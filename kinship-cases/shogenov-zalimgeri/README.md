# Дело: Шогенов Залимгери Каральбиевич (1916/1912 – 19.08.1943)

Исследование гибели под Харьковом и ближайшей родни уроженца с. Старый Черек (Кабардино-Балкария). Составлено 29.10.2026.

**Главное:** сержант, командир стрелкового отделения 1288-го стрелкового полка 113-й стрелковой дивизии; убит 19 августа 1943 г. у д. Боровое (Боровая) Змиевского района Харьковской обл.; похоронен в братской могиле в центре села (ныне с. Борова Чугуевского района). Отец — Шогенов К. Х. (вероятно, Каральби), жена в 1943 г. — Шагенова Аписа (Алиса?). Отождествление с дедом заказчика — рабочая гипотеза (семья помнит 1941–1942 гг.).
