# Дело: Шогенов Залимгери Каральбиевич (1916/1912 – 19.08.1943)

Исследование гибели под Харьковом и ближайшей родни уроженца с. Старый Черек (Кабардино-Балкария). Составлено 29.10.2026; прогон 2 — 30.10.2026; прогон 3 (документы «Памяти народа») — 30.10.2026.

**Главное:** сержант, командир стрелкового отделения 1288-го стрелкового полка 113-й стрелковой дивизии (64 ск 57 А); призван Урванским РВК в декабре 1941 г. (команда 053 — в 3-й нацкавполк 115-й Кабардино-Балкарской кавдивизии); убит 19 августа 1943 г. у с. Боровое (Боровая) Змиевского района Харьковской обл., когда его полк (двухбатальонного состава) удерживал выс. 198,9 западнее села под шестью контратаками пехоты с танками (по документам штабов 113 сд, 64 ск, 57 А); похоронен в братской могиле в центре села (ныне с. Борова Чугуївського района, вул. Центральна, памятник истории 3798-Ха) — на плите выгравировано «ШОГЕНОВ З.К.», в Книзі Пам'яті України (т. 18, 2001) — «Шогенов Зомінегері Караївбійович, похований: с. Борова». Отец — Шогенов К. Х. (вероятно, Каральби), жена в 1943 г. — Шагенова Алиса, сын — Барасби Залимгериевич (1939, по сведениям семьи). Отождествление с дедом заказчика подтверждено (село, год, отчество сына). Портрет — только в анкете «Дороги памяти» (опознание по подписи).
